# Run role-play without a Stage

Role-play is a Stage-free Performance: its Director derives the next action and completion from durable Character Turns, Performance Segment ordering, and structured DM Tool calls. Theater permits presets with zero Stages and gives Directors an ordered read of settled Character Turns reconstructed from durable Performance and Character Session records. The role-play Director owns the Character Turn Projection and returns the existing `act` or `complete` Decision; no separately persisted transcript, cursor, projector contribution, or synthetic scheduling Stage is introduced. A role-play Stage should be introduced only if future behavior requires independent durable domain state that cannot be derived from those records.
